# Activity 5 – AI Prompt Log

## Prompt ID

BUG-REPORT-001

---

## Version 1

You are a Senior QA Engineer.

Write a professional Bug Report following IEEE 829 / ISTQB standards.

Rules:

- Use ONLY the verified information provided.
- Do NOT invent missing information.
- If information is unavailable, write N/A.
- Distinguish Severity from Priority.
- Root Cause must come only from the Human Verification result.
- Suggested Fix should be practical and technical.
- Output in Markdown.

Required sections:

- Bug ID
- Title
- Severity
- Priority
- Status
- Environment
- Preconditions
- Steps to Reproduce
- Expected Result
- Actual Result
- Evidence
- Root Cause (Verified)
- Suggested Fix
- Trace (Test Case / Requirement)

Input:

- Activity 3 Root Cause Hypotheses
- Activity 4 Human Verification
